# Responsive Dashboard & Authentication UI

A responsive web application built with HTML5 and CSS3, featuring a modern admin dashboard layout and custom authentication pages (Sign In & Sign Up).

---

##  Features

- **Responsive Dashboard Layout**: Uses CSS Grid for desktop side-by-side layout and smoothly transitions to Flexbox on mobile viewports 
- **Fixed Mobile Navigation**: Sticky top horizontal action bar on small screens for easy navigation.
- **Glassmorphism Sign In & Sign Up UI**: Modern centered form layout overlaying a full-bleed dark blurred background.
- **Pure CSS Styling**: Hand-coded CSS without external UI frameworks, utilizing CSS custom variables, Flexbox, and Grid.
- **Icon Integration**: Powered by FontAwesome for UI icons.
